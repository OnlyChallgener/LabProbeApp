# AI 助手界面约束

本文件是极客网探 AI 助手的强制视觉与交互契约。新增或修改 `feature/assistant` 的页面前必须阅读；与默认 Material 组件的外观冲突时，以本文件为准。

## 绝对禁止

- 不使用深蓝色实心主按钮；AI 助手的唯一主操作色为薄荷绿 `#119A73`。
- 不使用方形或近方形输入框、按钮、卡片；输入与操作控件最小圆角为 18dp，信息面板为 24dp，标签使用全圆角。
- 不使用灰色投影、黑灰浮层或任何明显的矩形阴影；AI 助手页面的 `Surface` 必须显式设置 `tonalElevation = 0.dp` 与 `shadowElevation = 0.dp`。
- 不使用灰色按钮。次操作为透明底 + 薄荷绿描边，禁用态只降低对比度，不得改为灰色实心块。
- 不使用紫色、粉色的下拉框、卡片、弹窗、底部抽屉、展开层或页面。默认 Material 的紫色/蓝色状态色不得裸用。
- 不因轻触悬浮助手出现扩散式方形背景、遮罩或阴影。

## 版式与组件

- 使用 `AiTone`、`AiPanel`、`AiAction`、`AiFormField` 和 `AiToggle`；不得在助手页面直接新增未定制的 `Button`、`OutlinedButton`、`OutlinedTextField`、`SuggestionChip` 或 `AlertDialog`。
- 页面是浅色、留白充足的移动端单栏。内容用细边框区分层级，不能用多层大卡片包裹整个页面。
- 错误、确认和状态反馈在当前页面内展示；除系统权限外，不使用弹窗或底部页承载操作。
- 写操作仍需要明确的二次确认，但确认内容应是页面内的圆角提示面板，不能使用模态弹窗。

## 悬浮助手

- 默认贴右边并露出约一半，容器必须裁剪溢出内容，不能看起来漂在页面中间。
- 单天线、小型机器人头部；不能增加双天线、文字气泡或“轻触展开”等提示文案。
- 第一次轻触以 200–260ms 的平滑位移完整出现；第二次轻触进入对话；约 3.8 秒无操作后平滑缩回。
- 支持上下拖动，拖动结束后保持当前位置；动画只作用于位移和轻微缩放。

## 验收清单

1. 截图中没有深蓝实心按钮、方形输入框、灰色阴影或紫粉色浮层。
2. AI 设置、AI 对话、Token 用量、微信绑定页面使用同一套薄荷绿与圆角边框语言。
3. 悬浮助手半贴右边、展开与缩回均有平滑动画，且不产生矩形扩散效果。
4. 新组件在提交前须检查是否显式关闭了 elevation，避免 Material 默认样式回流。
