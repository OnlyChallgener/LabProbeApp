# 用网通知提醒 P1

## 已实现

- 五个独立开关：设备、游戏、视频、支付类访问、社交；旧四项保持，社交默认关闭。
- 保存接口支持部分更新，不改变其他类别；每类独立版本，不因修改另一类开关重置活动。
- 明确区分 `recordKind=activity` 与 `recordKind=reminder`。足迹展示真实活动，不把游戏／支付等访问再复制成设备用网。
- 游戏／视频保留10分钟、社交30分钟，按应用活动达标；设备级开始提醒基于实际活动区间合并后5分钟。后续完整设备规则放在P3。
- 实际源事件ID优先匹配；没有可信单次结束标识时展示已确认活动范围，不冒充精确结束时间。
- 已确认源事件结束时更新同一条活动记录；重复刷新不创建新的提醒。
- 手动刷新增加经过项目、路由器、设备校验的接口，读取儿童上网最近三天真实报告，更新活动，再同步当前提醒。
- 历史刷新不重置正在观察的提醒基线；无最新数据明确失败，不将查询时刻当成实际活动时刻。
- APP保留原缓存、图标缓存和原位更新；新数据返回前不清空旧列表。
- 为没有加入儿童上网的已知终端复用现有统计ID，避免后端记录有数据、前端按另一身份查不到。
