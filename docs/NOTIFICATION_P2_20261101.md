# 用网通知 P2：设置弹窗与分类记录

## 本阶段实现

- 五个独立提醒行：类型图标、名称、短描述、设置入口、独立开关。
- 共用底部弹窗，主页面开关直接保存；弹窗先改草稿，保存才下发，取消不改配置。
- 设备：开始、结束、深夜、长时间独立配置和长时间阈值。完整触发规则仍属 P3，本阶段不会冒充已实现全部触发。
- 游戏／视频／社交共用关注应用与时长组件。分类直接来自儿童上网目录，默认全部该类别；可选择指定应用。分钟严格校验1—1440整数。
- 支付选择已验证服务ID，不设时长，不判断支付完成。
- 后端保存配置版本，局部保存只更新对应分类的观察基线；游戏、视频、社交实际使用所设阈值与应用过滤。
- 独立通知记录页：全部／设备／游戏／视频／支付／社交，日期分组、倒序、最近三个北京时间自然日；不重复显示设备名、不加记录尾箭头。
- 只显示实际 reminder 记录，activity 继续放在上网足迹；按路由器与稳定设备标识筛选。
- 分类切换保留缓存行，数据未变化不重建列表；真实应用图标沿用现有目录与缓存，长应用列表分批创建。
