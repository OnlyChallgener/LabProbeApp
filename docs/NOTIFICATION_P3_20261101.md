# 用网提醒 P3 实施记录（2026-11-01）

## 实现

HUB继续复用儿童上网的真实应用ID、类别、分钟活动区间和采集时间。实际活动、提醒事件、Android送达状态分开保存；应用结束修订只更新原活动，不重发提醒。按HUB/账号、项目、路由器与稳定设备身份隔离。

设备开始用网需累计5分钟有效活动；结束需连续10分钟无活动且采集健康；深夜按北京时间22:00—06:00，每连续时段一次；长时间默认120分钟。游戏/视频/社交使用分类应用及已保存阈值，每连续应用活动达标一次。支付只记录已验证服务访问，不判断付款完成。稀疏汇总区间不当作连续使用时长，网络活动不表述为屏幕使用。

新规则或配置修订建立新基线，不补发开启之前的活动。数据中断不当作结束用网。跨午夜保留连续时段，清理今天及前两天以外的记录。

APP启动恢复登录后，唯一接收器先补齐分页记录，未通知事件合成一条“用网提醒汇总”；连接后的新事件各发普通通知。权限关闭照常同步但不记已送达。送达账本、游标、点击目标落盘，事件修订/刷新/重启不重发。若进程恰在系统通知发送与本地落盘间结束，同稳定通知标识覆盖原通知；不宣称操作系统提供跨进程事务。

通知点击与长轮询使用不同工作线程，避免等待15秒才跳转。单设备打开对应记录并定位；多设备先选择项目/设备，重新核对授权和实际MAC再打开。退出登录/换HUB立即取消旧请求，重连10秒起退避至120秒。

旧服务仅保留停止自身的兼容壳，不启动前台服务，不隐藏前台服务所需通知；不接厂商推送，不发连接状态提醒，不高频后台定时轮询。APP进程结束时HUB留存，下一次打开再收取。
