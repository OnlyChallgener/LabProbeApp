# WireGuard / STUN 操作同步验证计划

> 2026-11-25 补建：历史 CI 仍引用此文件名，原文不在当前仓库；以下为当前源码适用的验证计划，不是历史测试结果。

## 验证计划

- Python 静态契约测试：校验规则 ID 归属、修订号、远端操作顺序、取消和失败状态、收藏夹显式删除语义及 GitHub Actions 配置。
- Kotlin 单元测试及 Compose 测试：验证真实模型序列化、工作区隔离、规则绑定和 UI 状态。静态断言不替代 Kotlin 执行。
- GitHub Actions 使用固定签名构建 APK，并保存测试报告。独立测试分支仅产生测试预发布，不覆盖生产渠道。
- HUB 与 LabRelay 运行各自完整测试，交叉编译 ARM64/ARMv7。
- WAN1 的入站、防火墙、实际出口、回程路由和多线路流量必须在真实设备上验证；模拟或静态测试不能证明实机成功。
