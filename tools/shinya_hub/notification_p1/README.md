# P1：独立开关与真实活动

本仓库的官改 APP 使用补丁构建，当前工作区还包含大量其他功能的未提交修改。
因此本阶段提交只记录相对于开工时 APP 源码、线上 HUB 源码的精确差异，不整体提交这些混合文件。

- `android.patch`：`HubPages.java` 中第五个开关、社交显示、活动与提醒分离、刷新真实查询、旧记录替代去重。
- `backend.patch`：当前线上三个模块的局部差异，包含独立规则、统计身份映射、刷新接口与新活动观察器接线。
- `../notification_rules.py`、`../notification_activity.py`：新增后端源文件，部署时放入 `shinya_hub` 包。
- `source-manifest.json`：补丁前后源码哈希。必须先核对基线，不能将补丁直接套到其他旧版本。
- `test_p1.py`：在真实线上包的隔离副本中验证，不向路由器写配置。

构建使用当前工作区 `python tools/shinya_hub/build_internal.py --abi arm64-v8a`。
源码补丁只描述 P1，测试包另包含此前已经完成但未打包的信号覆盖输入框样式修订。

P2 的独立通知记录页面与设置弹窗、P3 的打开 APP 后汇总系统通知尚未进入本阶段。
当前接收服务继续停用；不会出现连接状态常驻通知。
