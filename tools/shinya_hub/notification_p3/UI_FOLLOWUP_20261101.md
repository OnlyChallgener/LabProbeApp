# P2/P3 交互验收后的补足

本轮以已安装并通过十次返回重进的 hub.38 为基线，只调整通知设置和记录界面，不修改儿童上网统计、事件触发规则或 HUB 部署。

## 已发现并修正

- 关注应用管理只读取已缓存图标，真实目录有图标但首次打开仍全为默认图标。共用图标接口增加异步加载，直接使用儿童上网目录中真实应用 ID 对应链接，复用现有哈希校验、认证代理和磁盘缓存；不按名称猜测图标。
- 图标请求使用独立、有界的两个工作线程，不占用保存/刷新队列。相同应用请求合并，页面退出或账号变化后不更新旧画面，模块释放时关闭工作线程。失败保留统一默认资源。
- 通知记录增加当前分类的青绿色选中背景；保留原分类数据与原位行更新方式。
