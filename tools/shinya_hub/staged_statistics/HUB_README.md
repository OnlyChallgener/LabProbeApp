# 星耀家 Hub

独立部署在 NAS，兼容星耀家 APP 的保留页面与固件命令协议。

## 当前范围

1. 按官方设备主动上报的思路建设自己的 HUB，与官方云并行运行；目前不替换官方连接。
2. 支持账号下多个项目，每个项目可登记单台或 Mesh 多台设备，各设备可以处于不同网络。
3. 保持 APP 布局，逐项实现保留功能；删除广告、资讯、反馈、问卷、教程、手机验证码及微信登录。
4. 信号工具与上传户型图后摆放路由器的模拟仍在范围内。WEB/RDP 已完成通道调试研究。

`labprobe-hub` 的设备协议实现作为参考；此项目使用自己的进程、数据目录和配置。

已验证实际拉黑、回读及解除，接入首次接入时间、今日流量与占比、速度曲线、本地稳定性评分。
全国平均水平已移除。评分来自自身采集数据，不代表已复刻官方算法。
49 项后台测试通过。100 台设备、每台 30 终端的隔离合成接收测试共 300 帧无失败；未进行 100 个真实网络客户端和 50 个同时在线 APP 压测。

官方账号登录、Token 刷新、项目与设备查询、独立申请 WEB/RDP 通道已成功验证；实际路由器反向 SSH 目标和 RDP 协商响应已核对。
HUB 自己的鉴权不依赖官方账号 Token。官方项目 ID 可作为外部对应关系，不能代替权限校验。

详见 [通道、鉴权与容量报告](docs/cloud-sync-findings.md)。

## 缓存与性能

项目登记与最后成功数据持久保存，项目列表不等待所有设备联网。设备异常不清空旧数据。
服务端合并每台设备的待处理快照、按序列号去重、一帧一次事务，独立设备 Topic 权限限制上报范围。

当前路由器原型采用有超时的单次 MQTT 发布和 RAM 最新快照，NAS 接收端保持 MQTT 长连接。
稳定固件长连接客户端、按 APP 前后台自动调节采集频率、历史数据保留期限尚未实现。
