### 2. 根治官方诊断卡片点击闪退 BUG
- **官方缺陷定位**：
  - 官方诊断详情页（`DiagnoseDetail`, Hermes `FID 33246`）内部存在硬编码的非法伪 JSON 字符串：
    - `'{reboot_count: 1}'`（键名无双引号）
    - `'{flapCount: 1}'`（键名无双引号）
    - `'{upLinkSpeed: 100}'`（键名无双引号）
  - 当后端返回数据缺失 `problemDetail` 时，页面直接调用 `JSON.parse` 解析上述默认值，导致触发未捕获的 `SyntaxError`，引发 APP 闪退崩溃；
- **根治措施**：
  - **后端协议对齐**：`ShinyaHub` 生成诊断详情时，全量填充合法标准的 JSON 字符串；
  - **Hermes 字节码原地修复**：在 bundle 字符串表中将这 3 处非法伪 JSON 替换为等长合法的 JSON 格式字符串，离线或缺省情况下也绝对不闪退。

### 1. 后端实现（`D:\Github\ShinyaHub\`）
- **`shinya_hub/xiaoxing.py`**：
  - **消息中心聚合**：`sync_notifications(key, project)` 自动轮询陌生终端、断网重连、干扰自动优化、用网日报并生成标准消息；
  - **无感考勤与随机 MAC 克服**：`watched_devices()` 与 `device_presence_timeline()` 根据 static IP、hostname 和备注名多重关联，按 45m 到家 / 15m 防抖计算时间轴；
  - **预设对话引擎**：`handle_send()` 识别自然语言或快捷指令，支持 10 类原版及 6 类 V2.0 专属预设卡片输出；
  - **诊断协议规范**：`make_diagnose_steps()` 产生 6 个步进式检测阶段，生成完整 `diagnosisProblemDetailMap`。
- **`shinya_hub/speedtest.py`**：对接路由器固件测速命令，提供 `/api/v1/hub/speedtest/{ports,servers,state,progress,history,start}` 轮询接口。
- **`shinya_hub/floor_engine.py` & `floor_bridge.py`**：全本地化墙体物理衰减仿真计算，替代原版外部云端渲染。

### 2. 客户端原生实现（`D:\Github\LabProbeApp\tools\shinya_hub\`）
- **`HubPages.java`**：
  - `notifyRemind()`：纯原生构建用网通知设置页，两张白底卡片、绿青色滑块（`TEAL`）、开关状态联动与保存；
  - `speedTest()`：复刻 `RouterSpeedTest.kt`，包含 `SpeedGaugeView`（弧形仪表盘）与 `SpeedCurveView`（贝塞尔动态测速曲线）；
  - `openURL()`：拦截 `speedTest` 与 `notifyRemind` 自定义 scheme，支持跨组件唤起。
- **`HubStationModule.java`**：
  - 注册 `@ReactMethod assistantSend`：把请求转发至 `ShinyaHub`，并将返回结果包装为 `[{"data": "<json string>"}]` 回调给 JS 模拟 WebSocket 事件推送；
  - 注册 `@ReactMethod speedTest` 与 `@ReactMethod notifyRemind`。

### 3. Hermes 字节码修补（`patch_bundle.py`）
- **恢复入口**：移除对 `ToolXiaoxing` 顶部横幅的隐藏，恢复小星助手完整导航路由；
- **虚拟本地 Bridge WebSocket**：
  - `FID 35710`：构建轻量虚拟对象，直接挂载 `onopen`, `onmessage`, `close`, `send`，通过 `setTimeout(ws.onopen, 20)` 触发已连接；
  - `FID 35717` (`ws.send`)：调用 `NativeModules.sta.assistantSend(payload, cb)`；
  - `FID 35719` (`cb`)：执行 `if (res) JSON.parse(res).forEach(ws.onmessage)` 将消息灌入前端；
- **测速重定向**：`FID 35703` 替换为 `NativeModules.sta.openURL(speedTestURL)`；
- **诊断防崩**：替换非法默认值，短路同网定位判断（`FID 35748`）。

## 四、注意事项与避坑指南

1. **绝对不要混淆项目代码库**：
   - ⚠️ `ShinyaHub` 是本项目专属的本地私有后端，包含小星助手 V2.0、本地户型模拟、测速与 MACC 桥接；
   - ⚠️ `labprobe-hub` 是另一个独立项目，两者的配置数据与代码严禁交叉混用。
2. **遵从指示暂不打包 APK**：
   - 当前已在 `test\_analysis\oct08-shinya-hub\index.android.bundle.patched` 成功生成并全量校验了打了补丁的 bundle；
   - 暂未执行 `apktool` / `gradle` 打包，保留当前工作区供您检查与确认。
3. **随机 MAC 识别机制说明**：
   - 安卓 10+ 手机默认开启“随机 MAC”，当手机重新连网时 MAC 地址可能变动；
   - 系统利用静态 IP、终端指纹与设备备注在后端自动完成跨 MAC 聚合，无需用户在手机端手动关闭“随机 MAC”。
4. **纯净化保障**：
   - 若在任何地方看到“意见反馈”、“问卷”等入口，均为官方已废弃残留，现已在补丁中完成深度清除。
