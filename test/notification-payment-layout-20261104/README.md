# 通知记录与支付／购物设置修正 · 2026-11-04

## 变更
- `HubNotifySettings.java`：统一使用几何绘制返回箭头，固定在标题栏中心；支付／购物仍归于同一个独立主开关，内部提供支付访问、支付次数、购物时长、购物次数四项规则，各自保存阈值。
- 每日概览四列，缩小图标与字号，灰色标签与蓝／紫／青色数值。小时柱使用原紫色渐变，移除底线，偶数小时刻度。点击小时更新同分类、同日期的概览；再次点击恢复全天，不请求接口或清空明细。
- `notification_preferences.py`：只扩展原有 payment 配置；兼容旧配置，次数 1—100，分钟 1—1440，部分更新保留其他字段。
- `notification_trigger_rules.py`：支付／购物使用共享儿童应用目录的稳定 ID 分流。支付及银行服务 ID 明确列于 PAYMENT_SERVICE_IDS；其余目录 0006 归购物。没有名称猜测，不宣称支付完成。访问按原始事件 ID（缺失时按应用和可信开始时间）去重计数，活动更新不重复；购物时长只使用真实 activeSeconds／minutes，不能用起止跨度替代。
